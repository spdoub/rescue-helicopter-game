# Shared art-style prompt

Prepend this to every Meshy generation so all assets match (see PRD: Art, audio and UI).

> Chunky, soft, toy-like low-poly 3D model in a playful diorama style. Rounded, slightly lumpy shapes with exaggerated proportions, like a vinyl toy or claymation prop. Bright, saturated, flat colours with simple large colour regions and minimal texture detail. Clean readable silhouette. No realistic wear, no fine surface detail, no text or logos. Single object, centred, neutral pose.

**Characters:** add "big hands, stubby limbs, simple dot eyes, no fingers detail, T-pose for rigging".
**Helicopter parts:** add "stubby and overloaded, visible duct tape patches, oversized rotor hub".
**Target budget:** props under 5k triangles, characters under 10k, helicopters under 20k.
